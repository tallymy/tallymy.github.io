Tally 將財務資料保存在你的裝置上。只有當你選擇匯出、備份、分享、連接自己的電腦或新增 Google 日曆提醒時，資料才會離開裝置。開發者只收到你自願傳送的意見回饋。

  • 無需註冊，沒有雲端帳本、分析、廣告或追蹤。Tally 安裝後可離線使用。可選的電腦連線使用你的區域網路。
  • 資料存在哪裡：帳本和收據照片保存在裝置的 IndexedDB 中：網頁版使用 Tally 網站的瀏覽器儲存空間，Android 應用使用其私有 WebView 儲存空間。開發者收不到帳本資料。備份和分享檔案是你主動建立的副本。
  • 收據由手機上的文字識別器（PaddleOCR）在本機讀取。照片從不上傳。儲存的照片會重新編碼，位置資訊因此被去除。
  • 網路請求：網站從 GitHub Pages 下載自身檔案；Android 應用內建這些檔案。開啟網站或電腦頁面會連接 GitHub Pages，其可能記錄 IP 位址等一般伺服器資訊。匯入 Google 試算表連結會從 Google 取得該試算表。可選電腦連線在區域網路交換連線資訊；財務紀錄不經過這個臨時 HTTP 介面。
  • 電腦連線（可選）：只有當你主動開始連線，並在兩台裝置上確認相同的數字後，電腦才會透過加密的 WebRTC 連線收到個人 RM 帳戶餘額及最近最多 200 筆紀錄摘要。不會傳送收據照片或商品明細。變更儲存在手機上。電腦頁面僅在暫時記憶體中保留資料，不為帳本建立消費資料庫或使用瀏覽器儲存空間。偵測到斷線後會清空顯示，重新連線需要再次批准。手機記住上次編輯的紀錄和清單位置；未儲存的輸入會清除。請使用可信的電腦：使用者、瀏覽器擴充功能或惡意軟體可能複製顯示的資訊。清空 Tally 頁面無法刪除他們已製作的副本。
  • 匯率（可選）：只有當你在外幣帳戶上點獲取今日匯率時，Tally 才會向 api.frankfurter.dev 查詢這一個匯率（歐洲央行匯率）。不會發送任何關於你或你財務的資訊。
  • 意見回饋：只有在你點「發送意見回饋」時，你的留言、你自願填寫的聯繫方式，以及應用資訊（Tally 版本、手機類型、瀏覽器、螢幕寬度、當前頁面和語言）才會透過 Google 表單發送給開發者。不包含任何關於你的錢、收據或帳戶的內容。離線時寫的留言會先留在手機上，恢復聯網後再發送。
  • 日曆提醒（帳單、習慣、每日提醒）是你自己選擇加入日曆的連結或檔案；由你的日曆應用儲存，而不是 Tally。
  • 應用鎖（可選）：你的 PIN 從不儲存，手機上只儲存它加鹽後的雜湊值。指紋或面容由手機驗證；Tally 只儲存一個識別碼，從不接觸你的指紋或面容。應用鎖用來防止別人打開應用。你也可以打開「加密這部手機上的資料」：你的紀錄和收據照片會用 PIN 或密碼加密儲存（AES-GCM），沒有它就讀不到，即使拿到手機的副本也不行；你的設定（語言、文字大小）不加密。如果忘了 PIN 或密碼，加密的資料無法復原。
  • 備份和匯出是你自己建立、自己決定存放位置的檔案。一旦分享出去，就適用該服務的條款。
  • 共同帳戶：「分享共同帳戶」生成的檔案只包含你標記為共同的帳戶、它們的記錄（以及你勾選的照片）、共同預算、用到的類別和你為共同記錄設定的名字。不包含個人帳戶的任何內容。除非分享時設了密碼，檔案不會加密：只透過你信任的應用發給你的伴侶。Tally 從不自行發送。
  • 刪除資料：設定 → 清除 Tally 資料會刪除本裝置上的帳本。清除網站資料會刪除網頁版的瀏覽器副本；清除 Android 應用資料或解除安裝會刪除應用副本。匯出、備份及獲准電腦使用者製作的副本不會被刪除。不會影響其他應用、照片或檔案。如需保留帳本，請先備份。

你的意見回饋和你的權利

意見回饋只用於修復 Tally 和回覆你。Google（Google Forms）替開發者儲存意見回饋，可能存放在馬來西亞境外，並在 12 個月後刪除。聯繫方式可不填；不填的話開發者無法回覆。請不要填寫身分證號碼或帳戶號碼。如要查看、更正或刪除你發送過的意見回饋，或撤回同意，請寄電子郵件到 fir1412dev@gmail.com，或透過「發送意見回饋」留下聯繫方式提出請求；你會在 21 天內得到答覆。如果意見回饋資料外洩，開發者會依法通知個人資料保護專員和受影響的人。未滿 18 歲？請先徵得父母或監護人同意再填寫聯繫方式。

Google 日曆提醒：如果你使用 Google 日曆連結，提醒的文字（例如「支付 Unifi」）會發送給 Google。
