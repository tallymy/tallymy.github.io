02 — 核對

04 — 稅務減免

報稅季，不必再翻一整箱收據。

Tally 根據收據上的文字，標出可能適用 LHDN 減免的消費。標錯了？改成「不是稅務減免」，或補選它漏掉的項目。天課和捐款會另外列出。減免收據的照片保留 7 年，隨時可以下載。上限請以 LHDN 公布為準。

常見問題

你一定想問。

還是不放心？Tally 是開源的，你可以在 GitHub 上看程式碼。

真的免費嗎？

真的。所有功能都免費，沒有付費進階版，也沒有廣告。這是一個用心做的個人作品，而且工作都在你的手機上完成，不需要花錢養伺服器。

我的資料會去哪裡？

留在你的手機裡。沒有帳號。收據在裝置上讀取，從不上傳。如果你要備份，只會在你選擇時存到你自己的 Google Drive 或檔案。

可以刪除收據照片嗎？

可以。在「設定 → 隱私 → 收據照片」裡，可以馬上全部刪除，或讓 Tally 自動刪除超過 30 天、90 天或一年的照片。記錄會保留：商店、日期、金額和項目。依時間清理時，Tally 會把可能符合稅務減免的消費照片保留 7 年（LHDN 可要求查看的期限）。選擇全部刪除的話，這些照片也會一起刪掉，由你決定。

Tally 會讀我的簡訊，或要我的網銀登入資料嗎？

不會。Tally 從不讀取你的簡訊或驗證碼（OTP），也從不要求網銀登入資料、銀行卡或密碼。它唯一會請求使用的是相機，用來拍收據；你也可以拒絕，改成手動輸入。只有你自己選擇匯入對帳單檔案時，銀行記錄才會進來。

為什麼需要連網？

第一次開啟、下載收據識別器（只需一次，約 30 MB）和自動更新時需要連網。之後就能離線使用。除此之外，它只在你要求時連網：你貼上的 Google Sheets 連結、你查詢的匯率、你送出的意見回饋，或你新增的日曆提醒。你的記錄和收據照片從不會被傳送出去。

幫爸媽安裝？

在他們的手機上開啟 tallymy.github.io，選好語言和大一點的字，再加入主畫面。到「設定 → 功能」選「簡單」，只保留基本功能。不需要帳號或密碼，記錄都留在他們自己的手機裡。

它讀得懂我的收據嗎？

褪色、皺巴巴、拍得遠或拍歪的照片都難不倒它，還認得超過 3,000 個馬來西亞連鎖品牌和店名。它不可能每次都對，所以會核對項目加總是否等於總額，並指出值得再看一眼的那一行。改過一次，下次 Tally 就記得。

從瀏覽器安裝的，算真正的 App 嗎？

它是一個網頁應用程式，可以安裝到主畫面，像 App 一樣開啟，開過一次後就能離線使用。

換手機怎麼辦？

在「設定」的「備份與恢復」建立備份檔，傳給自己（Google Drive、電子郵件、WhatsApp），再到新手機上恢復。因為沒有帳號，換手機前記得先備份。

稅務減免功能算稅務建議嗎？

不算。Tally 會標出可能符合減免的收據和項目，並保存每張收據的照片。它不了解你的個人狀況，也不會計算你能申報多少；每項減免都有上限和條件。這只是幫你提早準備的估算。哪些可以申報，請以 LHDN 的規定為準。

誰做的？

馬來西亞的一位獨立開發者。它是開源的（MIT），你可以在 GitHub 上看程式碼。有意見或發現 bug？到 GitHub 開 issue。

如果我不用了，或它不再更新呢？

你的資料在你的手機裡，隨時都能建立備份檔。程式碼以開源（MIT）方式放在 GitHub 上，不會被鎖起來。
