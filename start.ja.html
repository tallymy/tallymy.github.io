しくみ

しわくちゃのレシートから、ひと目でわかる家計へ。

01 — 撮る

かすれても、しわでも、横向きでも。ちゃんと読めます。

Tally は写真の傾きを直し、印字がかすれた部分もじっくり確かめながら、スマホの中だけで読み取ります。アップロードは一切ありません。レシートがなければ、金額を入力するだけでも大丈夫です。

02 — 確かめる

計算の過程も、ぜんぶ見せます。

割引、SST、サービス料、5セン単位の端数調整まで1行ずつ読み取り、品目の合計が総額と合うかを確かめます。おかしな行があれば Tally が知らせるので、その場で直せます。一度直せば、次からは覚えています。

03 — 仕分ける

一度の買い物を、品目ごとに。

大型スーパーでの一度の買い物に、食品も薬も掃除用品も入っていることがあります。Tally は品目ごとにカテゴリを分けるので、予算には本当に買ったものが反映されます。一度直せば、次からは覚えています。

04 — 税控除

申告シーズンも、レシートの箱をひっくり返さずに。

Tally はレシートの文字から、LHDN の税控除に使えそうな買い物に印を付けます。違っていたら「税控除の対象外」にするか、見落とした控除を選べます。ザカート（イスラム教の喜捨）と寄付は別枠で表示。控除用レシートの写真は7年間保存され、いつでもダウンロードできます。上限額は LHDN で確認してください。

購入前のチェック

買っても大丈夫？買った後ではなく、買う前に。

値段を入力すると、Tally がこれから30日間（今あるお金、給料、請求、ふだんの支出）を1日ずつたどり、月末ではなく残高が一番少なくなる日で判断します。給料日前に一度でも足りなくなれば、給料で持ち直しても「ぎりぎり」と判定します。記録がまだ少ないうちは、おおまかな見込みだと伝えます。

無料の理由

無料なのは、お金をいただく理由がないから。

Tally は好きで作っている個人プロジェクトです。処理はすべてあなたのスマホの中。データを預かるサーバーがないので、運営費はほとんどかかりません。有料プランはなく、すべての機能を誰でも無料で使えます。

データはスマホの中に。外に出るのは、自分で選んで Google ドライブやファイルにバックアップするときだけ。
オープンソース（MIT）。すべてのコードを GitHub で読めます。
有料プランなし。すべての機能を、すべての人に。
レシート写真はいつでも削除可能。記録は残ります：店名、日付、金額、品目。

よくある質問

気になること、お答えします。

まだ不安ですか？Tally はオープンソースなので、GitHub でコードを読めます。

本当に無料ですか？

はい。すべての機能が無料で、有料プランも広告もありません。好きで作っている個人プロジェクトで、処理はスマホの中で行うので、維持費のかかるサーバーもありません。

データはどこに保存されますか？

あなたのスマホの中にとどまります。アカウントはありません。レシートは端末の中で読み取り、アップロードはしません。バックアップする場合も、あなたが選んだときに、自分の Google ドライブかファイルに保存されるだけです。

レシート写真は削除できますか？

はい。設定 → プライバシー → レシート写真 で、今すぐすべて削除するか、30日・90日・1年より古い写真を自動で削除するよう設定できます。記録（店名、日付、金額、品目）は残ります。古い写真を自動で整理するときも、税控除の対象になりそうな買い物の写真は、LHDN から提出を求められる可能性のある7年間は残します。すべて削除を選べば、それらも消えます。決めるのはあなたです。

Tally は SMS を読んだり、銀行のログイン情報を求めたりしますか？

いいえ。Tally が SMS やワンタイムパスワード（OTP）を読むことはなく、銀行のログイン情報、カード、暗証番号を求めることもありません。使わせてほしいとお願いするのはカメラだけ（レシートを撮るため）で、断って手入力にしても大丈夫です。銀行の記録が入るのは、あなたが自分で明細ファイルを選んだときだけです。

なぜインターネットが必要なのですか？

初めて開くとき、レシートの読み取り機能を一度だけダウンロードするとき（約30 MB）、そして自動更新のときです。その後はオフラインで使えます。それ以外にネットにつながるのは、あなたが頼んだときだけ：貼り付けた Google Sheets のリンク、調べた為替レート、送ったフィードバック、追加したカレンダーのリマインダー。記録やレシート写真が送られることはありません。

親のスマホに入れてあげたい？

親のスマホで tallymy.github.io を開き、言語と大きめの文字を選んで、ホーム画面に追加します。設定 → 機能 で「シンプル」を選べば、基本の機能だけになります。覚えてもらうアカウントやパスワードはなく、記録は親のスマホの中に残ります。

レシートをちゃんと読めますか？

かすれた写真、しわくちゃの写真、遠くから撮った写真、横向きの写真にも対応し、マレーシアの3,000以上のチェーンと店名を見分けます。毎回正しいとは限りません。だからこそ、品目の合計が総額と合うかを確かめ、もう一度確かめたほうがいい行を知らせます。一度直せば、次から Tally は覚えています。

ブラウザからインストールしても、ちゃんとしたアプリですか？

ホーム画面にインストールできる Web アプリです。アプリと同じように開け、一度開けばオフラインでも使えます。

スマホを買い替えたら？

設定の「バックアップと復元」でバックアップファイルを作り、自分宛てに送ります（Google ドライブ、メール、WhatsApp）。新しいスマホでそれを復元すれば完了です。アカウントがないので、買い替える前に必ずバックアップを。

税控除の機能は税務アドバイスですか？

いいえ。Tally は控除の候補になりそうなレシートや品目に印を付け、それぞれのレシート写真を保存します。あなたの事情はわからないので、いくら申告できるかは計算しません。控除にはそれぞれ上限と条件があります。あくまで準備に役立つ目安です。何が申告できるかは、LHDN の規則で確認してください。

誰が作っているのですか？

マレーシアの個人開発者がひとりで作っています。オープンソース（MIT）なので、GitHub でコードを読めます。ご意見やバグの報告は GitHub の Issue へ。

使うのをやめたら、または更新が止まったら？

データはあなたのスマホの中にあり、いつでもバックアップファイルを作れます。コードは GitHub でオープンソース（MIT）として公開されているので、閉じ込められることはありません。
