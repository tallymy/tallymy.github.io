02 — 核对

Tally 把计算过程摊开给你看。

它逐行读取，包括折扣、SST、服务费和 5 分进位，再核对项目合计是否等于总额。哪一行看起来不对，Tally 会指出来，让你修改。改一次，下次它就记住了。

03 — 归类

一趟采购，按项目分好类。

去一趟大型超市，可能同时买了食物、药品和清洁用品。Tally 把每个项目归入各自的类别，让预算反映你真正买了什么。改一次，下次它就记住了。

常见问题

问得好。

还不放心？Tally 是开源的，你可以在 GitHub 上查看代码。

真的免费吗？

是的。所有功能都免费，没有付费高级版，也没有广告。这是一份热爱之作，而且工作都由你的手机完成，不需要花钱养服务器。

我的数据会去哪里？

留在你的手机里。没有账号。收据在设备上读取，从不上传。如果你要备份，只会在你选择时存到你自己的 Google Drive 或文件。

可以删除收据照片吗？

可以。在“设置 → 隐私 → 收据照片”里，可以马上全部删除，或让 Tally 删除超过 30 天、90 天或一年的照片。记录会保留：商店、日期、金额和项目。按时间整理时，Tally 会把可能符合税务减免的消费照片保留 7 年（LHDN 可要求查看的期限）。选择全部删除，这些照片也会一起删掉，由你决定。

Tally 会读我的短信，或要我的银行登录吗？

不会。Tally 从不读取你的短信或验证码（OTP），也从不要求银行登录、银行卡或密码。它唯一会请求使用的是相机，用来拍收据；你也可以拒绝，改为手动输入。只有你自己选择导入对账单文件时，银行记录才会进来。

为什么需要联网？

第一次打开、下载收据识别器（只需一次，约 30 MB）和自动更新时需要联网。之后就能离线使用。除此之外，它只在你要求时联网：你贴上的 Google Sheets 链接、你查询的汇率、你发送的反馈，或你添加的日历提醒。你的记录和收据照片从不会被发送。

帮爸妈装？

在他们的手机上打开 tallymy.github.io，选好语言和较大的字体，然后添加到主屏幕。在“设置 → 功能”里选“简单”，只保留基本功能。不需要账号或密码，记录都留在他们自己的手机里。

它读得懂我的收据吗？

褪色、皱了、远拍或拍歪的照片它都能应付，还认得超过 3,000 个马来西亚连锁店和店名。它不会每次都对，所以它会核对项目合计是否等于总额，并指出值得再看一眼的行。改一次，下次 Tally 就记住了。

从浏览器安装的，算真正的应用吗？

它是一个网页应用，可以安装到主屏幕，像应用一样打开，打开过一次后就能离线使用。

换手机怎么办？

在「设置」里，「备份与恢复」会生成一个备份文件。把它发给自己（Google Drive、邮箱、WhatsApp），再在新手机上恢复。因为没有账号，换手机前记得先备份。

税务减免功能算税务建议吗？

不算。Tally 会标出可能算作减免候选的收据和项目，并保存收据照片。它不了解你的情况，也不会计算你能申报多少；每项减免都有上限和条件。这只是帮助你提前准备的估算。预知可申报哪些项目，请查看 LHDN 的规定。

谁做的？

马来西亚的一位独立开发者。它是开源的（MIT），你可以在 GitHub 上查看代码。有意见或发现 bug？在 GitHub 上提 issue。

如果我不用了，或者它不再更新呢？

你的数据在你的手机里，随时都能做备份文件。代码在 GitHub 上开源（MIT），不会被锁起来。
